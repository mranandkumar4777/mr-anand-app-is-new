    Settings

    Used for AI song detection and slide generation. Add several keys separated by commas: when one hits its rate limit the next is used automatically. Keys are saved in this app on this computer only (phones never receive them). Create one at aistudio.google.com/apikey.
    One model per line as provider:MODEL_ID (gemini, openrouter, openai, groq, ollama, or any provider you add above). If a model errors or is busy, the next line is tried, then the other providers' defaults. Leave blank for the built-in defaults. Listening needs a model that accepts audio: use Detect models to list the audio-capable ones for the providers that have a key. Other providers: name = key for built-in presets (openai, groq, together, mistral, deepseek, xai, ollama, lmstudio) or name | https://base-url/v1 | keys | Header: value; Header2: value for your own OpenAI-compatible endpoint. Detected songs are checked against public music catalogs (title and artist only are sent).
    With click-through ON you cannot drag or close the Live window with the mouse. Turn it OFF here to move it again.
    Best for OBS: add a Browser Source with the URL http://localhost:8787/live — it is transparent and follows the slides automatically (you don't even need the Live window open).
    Using Window Capture instead? Choose Transparent here (the Live window reopens without a border — drag it to move, Esc to close) and in OBS tick Allow Transparency in the Window Capture properties.
    A browser tab can't broadcast real NDI on its own — no web page can, since NDI needs raw network access browsers don't allow. The free NDI Tools app bridges that gap:
    1. Download & install NDI Tools from ndi.video (free).
    2. Open the Live window here (top left) and leave it running on its own.
    3. Run NDI Screen Capture (part of NDI Tools) and point it at just the "STAGE DISPLAY — PRESENTER" window.
    4. In OBS, install the free obs-ndi plugin if you don't have it, then + Add Source → NDI™ Source and pick the feed NDI Screen Capture is broadcasting.
    This sends the feed over your network, so — unlike Window Capture — it also works if OBS is running on a different computer than this one.
    Click the 📱 Phone button at the top of the window — it shows a QR code to scan and the link to type. It needs the small server running (PRESENTER.bat / PRESENTER.app / presenter.sh, or node server.js) and this window opened from http://localhost:8787/.
    The Connection PIN is what a phone types (or scans) to connect. It can only be changed here, on the computer running PRESENTER — never from a phone. Changing it signs every phone out.
